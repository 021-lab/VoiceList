# Журнал решений

Решения владельца проекта. Новое предложение, которое им противоречит, сначала
сверяется с этим списком: агент напоминает решение и спрашивает, меняем ли его.
Отменённое решение не удаляется, а помечается отменённым со ссылкой на новое.

| Дата | Решение | Причина |
|---|---|---|
| давно, подтверждено 2026-10-18 | Голос при удержании задачи распознаётся на сервере: клиент шлёт звук, а не браузерную расшифровку. Пока не сделано — сейчас работает браузерный распознаватель. | Браузерное распознавание путает имена и редкие слова и не знает слов из списка. |
| 2026-10-18 | Ветка `Claude/live-button` выкатывается сразу на прод (`npm run deploy:prod`), дев — только по прямой просьбе. Не ветвиться от `main`. | `main` отстаёт и не знает поля `title`; выкат из него роняет прод. |
| 2026-10-18 | Текстовый агент и модель исправлений работают теми же инструментами, что голосовые модели. Команды показа экранов и `setTags` моделям не даются. | Форму команды собирает код, а не модель. |
| 2026-10-18 | Статус записи журнала считается по всей цепочке исправлений, как сейчас; переделывать по последнему шагу не нужно. | Решение владельца. |
| 2026-10-18 | Встроенный разборщик дорабатывается позже: корпус фраз из журнала, точность важнее охвата. | Сейчас приоритет — единые инструменты моделей. |
