# Журнал решений

Решения владельца проекта. Новое предложение, которое им противоречит, сначала
сверяется с этим списком: агент напоминает решение и спрашивает, меняем ли его.
Отменённое решение не удаляется, а помечается отменённым со ссылкой на новое.

| 2026-10-22 | Голос не проговаривает задачи. Услышав просьбу, он молча передаёт её на сервер (клиентское делегирование GPT-Live). Сервер выполняет её сам или спрашивает Sol. Результат приходит голосу как короткое подтверждение. Приоритет — сверхкороткие подтверждения, даже в ущерб ясности: «Клубника на паузе», «Сделал», «Готово». | Проговаривание задач замедляет разговор. |
| 2026-10-22 | Когда озвучивать результат. Меньше 3 с — сразу. Дольше 3 с — пока Sol думает, «Думаю», а результат в паузе: «Кстати, клубника на паузе». Если разговор ушёл дальше — не озвучивать. О неудаче сообщать всегда. | Решение владельца. |
