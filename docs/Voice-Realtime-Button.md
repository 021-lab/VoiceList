# Голосовая кнопка OpenAI Realtime

Документ описывает текущее целевое поведение голосовой функции в ветке
fix/issue-3-voice-button.

## Что видит пользователь

- Кнопка с микрофоном открывает голосовой диалог; повторное нажатие завершает
  его.
- Во время подключения отображается Подключение…, после открытия WebRTC-канала
  — Слушаю.
- Вкладка Диалоги показывает текстовую историю голосовых сессий.
- В настройках можно однократно задать OpenAI API key по защищённой ссылке и
  отредактировать системный промпт голосового агента.
- При уходе вкладки в фон или закрытии страницы голосовая сессия останавливается.

## Подключение

Модуль src/realtime-voice-agent.js получает доступ к микрофону, создаёт
RTCPeerConnection и data channel oai-events. Затем он передаёт SDP и актуальное
дерево задач в POST /api/realtime/session. Worker возвращает SDP answer,
после чего браузер обменивается аудио и Realtime-событиями непосредственно с
OpenAI.

Если сессия не запускается, ошибка попадает в локальную историю диалога, а
кнопка возвращается в неактивное состояние.

## Контекст и инструкции модели

При запуске в Realtime передаётся дерево с полями id, title, status и children.
Оно помещается в скрытый блок current_task_tree_json. Инструкции требуют:

- не перечислять и не озвучивать дерево без прямого запроса пользователя;
- отвечать на вопросы о состоянии задач без вызова инструмента;
- перед изменением использовать только точные id из дерева;
- при низкой уверенности, нескольких совпадениях или неясной речи коротко
  переспросить, а не угадывать;
- ждать результат каждой операции и говорить о результате только после него.

Полный снимок встроенных инструкций и tool schemas находится в
docs/realtime-agent-instructions.md. Runtime-источник — worker/openai-realtime.js.

## Инструменты модели

| Realtime tool | Действие в списке |
| --- | --- |
| addItem(line1) | Создать корневую задачу. |
| addChild(parentId, line1) | Создать обычную дочернюю задачу. |
| addInfo(parentId, line1) | Создать дочернюю задачу со статусом Info. |
| setStatus(taskId, status) | Сменить статус задачи. |
| editItem(taskId, line1) | Переименовать задачу. |
| setParent(taskId, parentId) | Переместить задачу к родителю или в корень при parentId: null. |

Model tool call исполняет браузер, а не OpenAI напрямую. Он преобразуется в
обычную WebSocket-команду и ожидает ACK Durable Object. Это сохраняет единый
путь изменений для UI и голосового агента.

После успешного ACK браузер отменяет незавершённую старую речь, очищает
аудиобуфер, передаёт модели function_call_output и запрашивает короткий новый
ответ только на основе результата операции. При rejected в модель передаётся
причина ошибки.

## Диалоги

История хранится только в localStorage браузера под ключом
voicelist.realtime-dialogues.v1. Для каждой сессии записываются:

- распознанная реплика пользователя;
- ответ агента;
- вызов инструмента и понятный результат операции;
- системная ошибка, если она возникла.

Хранится не более 30 диалогов и не более 240 сообщений в каждом. Журнал не
синхронизируется между устройствами и не является серверным аудит-логом.

## Остановка сессии

stopVoice закрывает data channel и RTCPeerConnection, прекращает все
MediaStream tracks, удаляет скрытый audio-элемент и завершает текущий диалог.
Он вызывается:

- повторным нажатием голосовой кнопки;
- закрытием data channel;
- событием visibilitychange, когда document.visibilityState равно hidden;
- событием pagehide.

Комментарии рядом с lifecycle-обработчиками объясняют, почему mobile browser
может иначе оставить WebRTC и микрофон активными в фоне.

## Что не делает функция

- Не вызывает /mcp и не использует public task API для изменения задач.
- Не загружает /api/tasks/tree.json при запуске; использует уже полученное
  приложением актуальное состояние.
- Не удаляет задачи: удаления нет в наборе голосовых tools.
- Не гарантирует персональную изоляцию настроек или истории на общем
  Durable Object main.
