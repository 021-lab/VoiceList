# COMMAND_RESOLVER — перевод транскрипции в команду

Разбор фразы на глагол и остаток. Вход — нормализованный поток токенов,
выход — ранжированные гипотезы команд. Сопоставление остатка с конкретной
задачей выполняет другой резолвер (`TASK_RESOLVER.md`); этот документ
заканчивается там, где начинается тот.

```
parseCommand(text, context) → Hypothesis[]
```

`Hypothesis = { command, actId, payload, слот, счёт }`

Вызывается из `resolveCommands` (`INPUT_HANDLING_STANDARD.md` §5). Для
команд с целью хвост гипотезы передаётся в `resolver.resolve`.

---

## 1. Форма фразы

**Глагол — только в начале.** Разбор с хвоста не выполняется: он порождает
фантомные гипотезы на обычных названиях («добавь всё что нужно» читалось
бы и как глагол «нужно» с текстом «добавь всё что»).

**Голое существительное командой не является.** Каждая форма начинается с
глагола либо с указательного «это»: «это в архив», а не «архив». Иначе
задача с названием «Архив» и команда архивирования становятся
неразличимы, а случайно произнесённое слово меняет статус.

**Слот один — весь остаток.** Предлоги в речи распознаются ненадёжно, и
опираться на них при разделении слотов нельзя. Поэтому у команды нет двух
слотов: контекст приходит жестом, остаток целиком идёт в единственный
слот.

```
<глагол или «это …»: 1..3 токена> [остаток]
```

Каждый фрейм задаёт форму остатка:

| Форма остатка | Значение |
|---|---|
| **обязателен** | Остаток — текст задачи или запрос для поиска цели |
| **пуст** | Команда безслотовая; непустой остаток означает, что это не она |

Это правило разводит большую часть коллизий. «Это на паузу» с пустым
остатком — перевод в паузу; «это на паузу купить молоко» — не команда
паузы вообще, потому что у неё остатка быть не может.

**Предлог в начале остатка отбрасывается.** Токены `в`, `во`, `на`, `к`,
`ко` в первой позиции остатка удаляются перед дальнейшей обработкой. Это
делает разбор нечувствительным к тому, расслышал движок предлог или нет:
«перенеси в ремонт» и «перенеси ремонт» дают один результат.

По той же причине формы с предлогом продублированы без него: «это в
архив» и «это архив», «это на паузу» и «это паузу». Движок теряет короткие
предлоги, и полагаться на их наличие нельзя.

## 2. Таблица фреймов

Контекст — элемент, прицепленный свайпом влево.

### Со слотом

| Команда | Контекст | Формы |
|---|---|---|
| `addChild`, родитель = контекст, иначе inbox | необязателен | добавь, добавить, запиши, записать, создай, создать, новая, новый, новое, нужно, надо, мне нужно, нужно сделать, надо сделать |
| `addChild`, родитель = контекст | обязателен | добавь подзадачу, добавь блокер, сначала, сначала нужно, сначала надо, сначала сделать, тут сначала, тут сначала нужно |
| `setParent`, новый родитель = цель из остатка | обязателен | перенеси, перенести, перемести, переместить, вложи, сделай подзадачей, это в |
| `editItem`, новый текст = остаток | обязателен | переименуй, переименовать, назови, назвать, исправь, исправить |
| `showSearch`, запрос = остаток | игнорируется | найди, найти, ищи, искать, покажи, показать, поиск, где |

### Без слота

| Команда | Контекст | Формы |
|---|---|---|
| `setStatus: Done` | обязателен | готово, готова, сделано, выполнено, закрой, закрыть, заверши, завершить, это готово, это сделано |
| `setStatus: Focus` | обязателен | сфокусируй, фокусируй, это в фокус, это фокус |
| `setStatus: Pause` | обязателен | отложи, отложить, это на паузу, это паузу, это потом |
| `setStatus: Archive` | обязателен | удали, удалить, убери, убрать, заархивируй, это в архив, это архив |
| `setStatus: Open` | обязателен | сними, сними фокус, сними паузу, возобнови, это в работу, это работу |
| `undo` | нет | отмени, отменить, откати, откатить, верни как было |

**«Удали» — это архивирование, а не удаление.** Голосового удаления в этой
версии нет; `deleteItem` доступен только через интерфейс.

## 3. Правила разбора

1. Нормализация и токенизация — те же, что в `resolver.js`: строчные,
   `ё→е`, пунктуация убрана.
2. **Самая длинная форма выигрывает.** Сопоставление идёт от трёх токенов
   к одному. Нашлась форма из трёх — формы из двух и одного для этой же
   фразы не проверяются.
3. Токены формы сопоставляются лестницей ярусов из `resolver.js`:
   точный → стем → опечатка. Морфология снимается без словаря форм.
4. Отбрасывается предлог в начале остатка (§1).
5. Проверяется форма остатка: слотовый фрейм с пустым остатком и
   безслотовый с непустым гипотезы не порождают.
6. Проверяется контекст: фрейм, требующий контекста, без него гипотезы не
   порождает.

### Параметры Θ команд

Отдельные от Θ целей — калибруются на своём корпусе.

| Параметр | Значение | Отличие от целей и почему |
|---|---|---|
| `STEM_PREFIX` | 4 | как у целей |
| `STEM_NUM/STEM_DEN` | 2/3 | как у целей |
| `TYPO_DIST` | 1 | как у целей |
| `TYPO_MINLEN` | 6 | строже: на пятибуквенных глаголах одна правка превращает «купи» в «купе», «сверь» в «сверни» |
| `W_EXACT`, `W_STEM`, `W_TYPO` | 3, 2, 1 | как у целей |

Указательное «это» и предлоги сопоставляются только точным ярусом: они
короткие, и стем с опечаткой на них дают ложные срабатывания.

### Счёт гипотезы

Кортеж `(n, w)`:

- `n` — сколько токенов заняла форма;
- `w` — сумма весов ярусов по этим токенам.

Сравнение лексикографическое. Длинная форма всегда бьёт короткую, при
равной длине точное совпадение бьёт стем, стем бьёт опечатку.

## 4. Процедура решения

```
parseCommand(text, context):
  T = tokenize(normalize(text))
  H = []
  for len in 3, 2, 1:
    for каждый фрейм с формой длины len:
      если токены T[0..len) совпали с формой по ярусам:
        остаток = T[len..], снять предлог
        если форма остатка и требование контекста соблюдены:
          H += гипотеза со счётом (n, w)
    если H непусто: прервать перебор длин
  если H пусто: Empty
  сортировка по (n, w); ничья по (n, w) → Vector; иначе One
```

### Инварианты

1. Слотовый фрейм с пустым остатком гипотезы не порождает.
2. Безслотовый фрейм с непустым остатком гипотезы не порождает.
3. Фрейм, требующий контекста, без контекста гипотезы не порождает.
4. Ничья по `(n, w)` — всегда `Vector`, молча не разрешается.
5. Ни одной гипотезы — `Empty`, фраза уходит в фолбэк на модель. Локальная
   гипотеза «просто добавить сказанное» не создаётся: случайная речь не
   должна превращаться в задачи.

## 5. Разбор коллизий

Проверка на непересечение — по парам, которые действительно сходятся.

**«перенеси» × «переименуй».** Общий префикс `пере` = 4 ≥ `STEM_PREFIX`,
но доля не проходит: короткое слово 8 букв, нужно ⌈2/3·8⌉ = 6, а общих 4.
Стем не срабатывает, команды не пересекаются. Правило доли здесь и
работает.

**«сделай подзадачей» × «сделано».** Корень общий, стем сработал бы. Но
`setParent` задан двухтокенной формой, а `Done` — однотокенной, и
двухтокенная проверяется первой. Одиночное «сделай» не является формой ни
одной команды и уходит в фолбэк.

**«это в …» как перенос × «это в архив» как статус.** Обе начинаются
одинаково. Различает длина: статусные формы трёхтокенные и проверяются
раньше, а после снятия предлога у переноса обязан остаться непустой
остаток. «Это в архив» — статус; «это в ремонт ванная» — перенос.

**«это на паузу» × задача с названием «Пауза».** Статус — безслотовая
команда с обязательным контекстом. «Перенеси паузу» имеет глагол в начале
и остаток «паузу», который уходит резолверу целей как название.
Пересечения нет: в одном случае слово стоит в позиции формы, в другом — в
позиции остатка.

**«верни как было» × «это в работу».** Первая — `undo`, без контекста,
вторая — `setStatus: Open`, с контекстом. Токены разные, требования к
контексту противоположные.

**«добавь» с контекстом и без.** Один фрейм, родитель выбирается по
наличию контекста: есть — подзадача, нет — inbox. Двух гипотез не
возникает.

## 6. Тестовый корпус

| Фраза | Контекст | Ожидаемый исход |
|---|---|---|
| «добавь купить молоко» | нет | `addChild` в inbox, текст «купить молоко» |
| «добавь купить молоко» | есть | `addChild` к контексту, текст «купить молоко» |
| «добавь всё что нужно» | нет | `addChild` в inbox, текст «всё что нужно» — глагол только в начале |
| «нужно сделать отчёт» | нет | `addChild` в inbox, текст «отчёт» — двухтокенная форма длиннее |
| «сначала купить краску» | есть | `addChild` к контексту |
| «сначала купить краску» | нет | `Empty` — фрейм требует контекста |
| «перенеси в ремонт» | есть | `setParent`, цель из «ремонт» |
| «перенеси ремонт» | есть | то же — предлог не влияет |
| «это в ремонт» | есть | `setParent`, цель из «ремонт» |
| «переименуй новый отчёт» | есть | `editItem`, текст «новый отчёт» |
| «готово» | есть | `setStatus: Done` |
| «готово молоко» | есть | `Empty` — безслотовая с остатком |
| «готово» | нет | `Empty` — требуется контекст |
| «это в фокус» / «это фокус» | есть | `setStatus: Focus` |
| «фокус» | есть | `Empty` — голое существительное командой не является |
| «сними фокус» | есть | `setStatus: Open` |
| «это на паузу» | есть | `setStatus: Pause` |
| «это на паузу купить молоко» | есть | `Empty` |
| «удали» | есть | `setStatus: Archive` |
| «найди смеситель» | любой | `showSearch`, запрос «смеситель» |
| «отмени» | нет | `undo` |
| «позвонить Ване» | любой | `Empty` → фолбэк |
| «сделай» | есть | `Empty` → фолбэк |
