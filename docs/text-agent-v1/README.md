# Текстовая модель — версия 1 (2026-10-22)

Снимок для сравнения со следующими версиями инструкции.

- `instruction.txt` — инструкция целиком, как её получает модель: правила (`AGENT_RULES` из
  `worker/v2/model.js`, версия #31–#32 прода) и JSON-схема инструментов.
- `corpus.json` — проверочный корпус, на котором она мерилась (45 фраз).
- `benchmark.md` — таблица прогонов и выводы на тот момент.
- `results.json` — итог каждого прогона: модель, параметры, точность по прогонам, задержка,
  и по каждой фразе — что модель сделала в каждом прогоне.

Прогнать эту версию снова: `node scripts/eval-text-agent.mjs --instruction docs/text-agent-v1/instruction.txt …`
