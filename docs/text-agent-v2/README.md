# Текстовая модель — версия 2 (2026-10-22)

Инструкция переписана как общий алгоритм: действия → цель → место новой задачи → правило →
даты → остаток в notDone. Примеры — новые фразы, не из корпуса (в версии 1 примеры совпадали
с фразами корпуса). Корпус тот же, что у версии 1 (`docs/text-agent-v1/corpus.json`).

- `instruction.txt` — инструкция целиком (правила и JSON-схема инструментов).
- `results.json` — прогоны версии 2: модель, параметры, точность, задержка, ответ по каждой фразе.
- `results-draft.json` — прогоны черновика версии 2. В нём X очищался только от слова-команды,
  не было запрета на addItem, а цель искалась по части названия. Это дало регресс и было исправлено.

Сравнение с версией 1 — в `docs/Text-Agent-Model-Benchmark.md`, раздел «Версия 1 и версия 2».
На проде остаётся версия 1.
