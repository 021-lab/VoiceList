# Живой голос GPT-Live с бэкендом Sol

Статус: на проде с версии #37, ветка `Claude/voice-sol`. Отменяет черновик отдельной кнопки «Бадди».

## Схема

```
человек ──голос──► gpt-live-1 ──<|SpawnThinking|>──► документ-DO (sideband)
                       ▲                                  │ разбор «добавь X» сам
                       │ commentary / thinking            │ или gpt-6.1-sol (Responses)
                       └──────────── короткое подтверждение ◄┘ инструменты исполняет DO
```

- Делегирование клиентское (`delegation: { type: "client" }`). Голос передаёт просьбу
  молча. DO берёт реплики человека с прошлой передачи и действует так:
  - «добавь X» с простым названием выполняет сам, без модели;
  - всё остальное отправляет в `gpt-6.1-sol` (рассуждения из настроек, сейчас `low`).
- Sol получает промпт, единую инструкцию по инструментам, дату и таблицу задач. Записи
  выполняет DO и сразу подтверждает их своим текстом («Клубника на паузе»). Если в одной
  фразе несколько изменений, Sol продолжает работу после первого подтверждения.
- Когда звучит подтверждение (решение от 22.10, второе):
  - пришло быстрее 3 с и человек не заговорил снова — звучит сразу;
  - иначе сервер придерживает его до следующего вопроса. Если вопрос ушёл к Sol, в паузе
    звучит «Думаю, кстати, голден на паузе». Если ответ без Sol — «Кстати, …». Если голос
    ответил на вопрос сам, без передачи на сервер, — «Кстати, …» звучит после его ответа;
  - придержанное подтверждение отбрасывается, если голос уже назвал эту задачу сам.
    Хранятся только два последних;
  - ответ или вопрос Sol звучит сразу, но если человек уже заговорил о другом, голос
    только запоминает его;
  - неудача звучит всегда, поздняя — с «Кстати».

  Решение принимает DO, потому что у голосовой модели нет часов. Каждое следующее
  сообщение для озвучивания ждёт тишины: голос договорил, и человек не начал говорить
  после передачи просьбы.
- Инструкция по инструментам одна (`composeToolGuide`), её получают и голос, и Sol. MCP не
  используется: через него медленнее.
- Промпты голоса и Sol меняет Sol, по просьбе и после того, как проговорит изменение.
  Промпт Sol читается заново на каждый запрос. В промпт голоса правка дописывается в
  работающую сессию.

## Проверено

- Юнит-тесты, 292 шт.
- Sol на настоящей модели, без голоса: статус, уточнение, «Входящие», перенос, дедлайн,
  два изменения в одной фразе, отказ удалять. До подтверждения 1,8–2,4 с.
- Настоящий `gpt-live-1` по WebSocket с синтезированной речью, тот же `LiveHost`, Sol,
  список в памяти. Цепочка «Поставь голден на паузу» → «Клубнику в фокус» → «Какую?» →
  «На даче». Результат начинает звучать примерно через 2,8 с после конца фразы.

## Ограничения

- Сразу после передачи просьбы `gpt-live-1` сам говорит одно слово («Ща», «Делаю»).
  Промптом это не убирается, удалось только сократить до одного слова.
- WebRTC из облачного контейнера не проходит, поэтому живая проверка шла по WebSocket.
- «Сегодня» считается в UTC.
