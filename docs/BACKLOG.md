## Закрыто

- **Резолвер команд** — `COMMAND_RESOLVER.md`: форма фразы, таблица
  фреймов, правила разбора, Θ команд, процедура решения, разбор коллизий,
  тестовый корпус.
- **Словарь голосовых форм** — там же. Область версии: добавление,
  перенос, переименование, статусы, поиск, отмена.
- **Ранжирование кандидатов.** Стек всегда однороден — в нём только цели.
  Команда однозначна по построению: три фильтра (длина формы, форма
  остатка, требование контекста) не оставляют места ничьей между
  командами. Смешанного стека не бывает, отдельное правило ранжирования не
  нужно.
- **Контракт ASR-адаптера** — `INPUT_HANDLING_STANDARD.md` §2: отказ
  доступа, обрыв, таймаут финального транскрипта, деградированный режим
  без промежуточных результатов. Каждый случай с сообщением пользователю
  и записью в журнал.
- **Частота пересчёта** — там же §4: пересчёт при появлении нового слова в
  промежуточном транскрипте плюс один на финальном.

## Важно, но обходится

### 1. Начальное состояние оверлея

Палец взвёл оверлей, речи ещё нет. Что нарисовано в этот момент — не
описано.

### 2. Хаптика

Палец закрывает точку взвода. Вибрация — единственный надёжный сигнал,
что оверлей поднялся. Нужно решить: есть ли она, на каких событиях
(взвод, переход между кандидатами, отмена).

### 3. Область действия жеста

Только список, или ещё журнал действий, экран поиска, поверх модалки.
Сейчас сказано «в любой точке экрана» — буквально это включает всё.

### 4. Глубина журнала

Каждая команда изменения хранит снимок для `undo`. Глубина и правило
вытеснения не заданы — на длинной сессии это вся история дерева в памяти.

### 5. Десктоп

Модуль объявлен для PWA, но мышь и клавиатура не описаны никак: нет
эквивалента удержания, свайпа и выбора по вертикали.

## Требование к CI

**Проверка непротиворечивости грамматики.** Однозначность команд держится
на текущем наборе форм, а не доказана в общем виде: две новые формы
одинаковой длины, одинаковой формы остатка и с одинаковым требованием
контекста могут сойтись по стем-ярусу. Нужен тест, который перебирает все
пары фреймов и падает, если такая пара появилась. Без него добавление
одного слова в словарь способно тихо вернуть неоднозначность.

## Вне этой версии

Названы явно, чтобы не всплывали как «забыли»:

- удаление голосом — «удали» переводит в архив, `deleteItem` только через
  интерфейс;
- теги голосом;
- сворачивание и порядок голосом — удобнее пальцем;
- визуальный стиль оверлея, темы;
- локализация — словарь только русский;
- автотесты самих жестов; тестируемость покрывает путь через поле ввода,
  но не касания.
