## Файловая структура

| Файл | Описание |
|------|---------|
| **list-manager.html** | Разметка страницы + вся логика (JS) |
| **list-manager.css** | Все стили, подключается через `<link rel="stylesheet">` |
| **list-data.js** | Массив `items[]` и счётчик `nextId` — подключается через `<script src>` перед основным скриптом |

## Функциональность для пользователя

| Жест / действие | Результат |
|---|---|
| **Тап** | Свернуть / развернуть подсписок (только у родительских элементов) |
| **Долгое нажатие** (370 мс) | Начать перетаскивание элемента и его дочерних элементов как группы |
| **Перетаскивание** | Сортировка. Смещение вправо во время тяга → +1 уровень вложенности |
| **Свайп вправо** (> 20% экрана) | Открывает правую панель:<br>🟢 **Вложенный** · 🔵 **Просмотр** · 🔵 **Изменить** · 🔴 **Удалить**<br>Вертикальный сдвиг пальца выбирает зону |
| **Свайп влево** (> 20% экрана) | Открывает левую панель тегов. Теги уже назначенные — внизу со знаком −. Вертикальный сдвиг выбирает тег |
| **Возврат в 20%** | Закрывает активную панель без выполнения действия |
| **Дроп в зону** | Выполняет выбранное действие |
| **Кнопка +** | Добавить новый элемент в конец списка |
| **Кнопка ↩** | Отменить последнее перетаскивание (один шаг undo) |
| **Кнопка 🎤** | PTT — удержать для записи голоса, отпустить для отправки на сервер |

## Структура данных

### list-data.js — плоский массив

```javascript
let items = [
  { id: 2,  line1: 'Хлеб ржаной' },
  { id: 26, line1: 'Бородинский', line2: '400 г', level: 1 },
  { id: 27, line1: 'Столичный',   line2: '500 г', level: 1 },
];
let nextId = 32; // монотонно растущий, ID не переиспользуются
```

### Поля элемента

| Поле | Тип | Описание |
|------|-----|---------|
| `id` | `number` | Уникальный идентификатор элемента |
| `line1` | `string` | Заголовок (обязательно) |
| `line2` | `string?` | Подпись / дополнительный текст |
| `level` | `number?` | Глубина вложенности: 0 = корень (по умолчанию), 1 = дочерний и т.д. |
| `collapsed` | `boolean?` | Подсписок свёрнут. Управляется через `toggleCollapse()` |
| `tags` | `string[]?` | Список тегов, назначенных элементу через левую панель |

## Вложенность и сворачивание

### render() — линейный проход по плоскому массиву

```javascript
let collapsedAt = Infinity;

items.forEach((item, idx) => {
  const level  = item.level || 0;
  const hidden = level > collapsedAt;   // глубже свёрнутого родителя

  if (!hidden) collapsedAt = item.collapsed ? level : Infinity;

  const hasChildren = (items[idx + 1]?.level || 0) > level;

  wrapper.style.display    = hidden ? 'none' : '';
  wrapper.style.marginLeft = (level * 24) + 'px';
});
```

**Примечание:** Дерево не строится — `level` читается прямо из элемента. Отступ = level × 24 px.

### toggleCollapse() — пишет флаг и вызывает render()

```javascript
function toggleCollapse(itemId) {
  const item = items.find(i => i.id === itemId);
  const hasChildren = /* следующий элемент глубже */;
  if (!hasChildren) return;
  item.collapsed = !item.collapsed;
  render();
}
```

## Изменение данных

| Действие | Мутация items[] |
|----------|-----------------|
| **Добавить** | `items.push({ id: nextId++, ... })` |
| **Добавить вложенный** | `items.splice(insertIdx, 0, { ..., level: parent.level + 1 })` |
| **Редактировать** | `item.line1 = ...; item.line2 = ...` |
| **Удалить** | `items = items.filter(i => i.id !== itemId)` |
| **Перетащить** | После drop DOM-порядок вrapперов читается обратно:<br>`items = [...wrappers].map(w => items.find(it => it.id === +w.dataset.id))` |
| **Тег** | `item.tags.push(tag)` или `item.tags.splice(idx, 1)` |
| **Отмена (undo)** | `items = undoSnapshot` — глубокая копия, сохранённая перед drag |

**Примечание:** Все данные живут только в памяти. Перезагрузка страницы возвращает состояние из `list-data.js`.

## Паттерн обновления UI

| Аспект | Описание |
|--------|---------|
| **Единая точка рендера** | `render()` полностью пересоздаёт DOM-список из `items[]` при каждом изменении |
| **Нет фреймворка** | Ванильный JS — `createElement`, `appendChild`, `innerHTML` |
| **Жесты** | `bindGesture(el, ...)` навешивается на каждый элемент при каждом `render()` |
| **Состояние жеста** | Глобальный `dragState` и локальные `rdAnchor` / `ldAnchor` в замыкании `bindGesture` |
| **Блокировка жестов** | Флаг `modalOpen` блокирует `touchstart` пока открыта модалка |
